# Rubrik Americas Field Enablement JSON Router: Week-1 Rollout Playbook

## Objective
Deploy a production-grade JSON router to govern all Americas field enablement requests, onboarding validations, and coaching workflows. This ensures every scenario is normalized, scored, and checkpointed for compliance, adoption, and operational excellence.

## Day 1-2: System Setup & Stakeholder Alignment
- Review the JSON router contract with Americas Enablement, Sales Ops, and Regional Directors.
- Map Rubrik’s onboarding, value selling, and methodology adoption rubrics to the router’s normalization logic.
- Configure input normalization for Rubrik segments (Enterprise, Commercial, SLED, Healthcare), products, and methodologies.

## Day 3: Pilot Launch & Human Checkpoint Training
- Route all new onboarding, coaching, and enablement requests through the JSON agent.
- Train enablement managers to review flagged cases (missing fields, PII, unsupported integrations) in the dashboard.
- Establish escalation protocols: any schema ambiguity, PII, or unsupported product triggers human review.

## Day 4-5: Live Case Handling & Feedback Loop
- Process real requests (e.g., onboarding progress, deal coaching, methodology adoption) using the router.
- For each flagged/escalated case, document the detected gap, human reviewer decision, and remediation steps.
- Collect feedback from sales leaders and enablement staff on clarity, auditability, and adoption impact.

## Day 6-7: Metrics & Continuous Improvement
- Track adoption metrics: % of requests normalized, % flagged/escalated, average human review time, and downstream impact on ramp time and win rates.
- Review false positives/negatives in escalation, refine normalization and policy rules.
- Prepare a Week-2 report for the GVP Americas and Global Enablement, highlighting readiness gaps closed, compliance wins, and next-step recommendations.

## SOPs & Adoption Metrics
- All onboarding and enablement requests must pass through the JSON router.
- Human review is mandatory for any flagged case (missing/ambiguous fields, PII, unsupported SKU).
- Adoption metrics: 95%+ structured normalization, <24h human checkpoint turnaround, and measurable reduction in onboarding ramp time.
